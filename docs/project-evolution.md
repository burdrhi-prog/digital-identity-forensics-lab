# Project Evolution and Career Relevance

## Origins
This work began as an independent investigation portfolio rather than a conventional software project. Over time, the need to compare provider records, preserve corrections, and explain uncertainty led to structured workbook workflows, identity graphs, and proposed automation.

## What has been done
- Developed a multi-provider, multi-year evidence organization approach.
- Organized original records and derived timelines using a master workbook.
- Worked with device/client identifier distinctions, source-linked correlations, and conflicting records.
- Iterated on analytical rules and documented unresolved attribution.
- Developed related GitHub projects for Python event correlation, human–AI evaluation, and a consumer-facing identity-security product concept.

These are **independent research and portfolio activities**, not claims of paid SOC experience, formal forensic imaging, validated chain of custody, or completed software products.

## Employer-relevant capabilities
Evidence management, IAM/security event review, data quality, technical writing, incident timeline reconstruction, fraud operations research, spreadsheet modeling, hypothesis testing, and human-in-the-loop analysis.
